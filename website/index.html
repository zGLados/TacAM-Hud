Why another HUD?

Paid broadcast HUDs are great – and too expensive for community tournaments, LAN parties and smaller streams. TacAM HUD is the free alternative: everything a CS2 broadcast needs, running on your own PC, with the code open on GitHub.

Built by zGLados for the TacAM community, developed with the help of AI. Every feature is tested in CS2 and OBS, and every build comes from the public repository. There is no paid version and no donation button – if you want to give something back, help make it better.

What runs where

Most of TacAM only reads CS2's game state (GSI) and works with a normal, VAC-secured CS2. Camera control needs CS2 started through HLAE, which runs the game with -insecure – TacAM starts it that way for you, on the observer PC only.

Normal CS2 GSI only, VAC-secured

  • HUD, live statistics, radar, kill feed
  • Scenes, overlays, director, map veto
  • Teams and players, theme editor, imported HUDs
  • OBS, Stream Deck / Companion, signals

CS2 via HLAE -insecure, observer PC only

  • Saved camera views and camera paths
  • Free camera when a demo loads
  • Pick a player by click or Stream Deck, next / previous player
  • CS2 auto director as a button
  • Console commands on demo load and back in the menu

Why: on Windows CS2 only opens its console to other programs when started through HLAE (or Workshop Tools), and both run insecure. Fine for demos and your own servers; for live GOTV the server may need tv_secure_bypass 1. Players' PCs are never touched.

Live in a few minutes

  1. Install. Download the installer and run it. Code signing is being set up – if Windows SmartScreen warns, choose More info → Run anyway.
  2. Connect CS2. Settings → Install GSI config, then restart CS2.
  3. Add it to OBS. A browser source with http://127.0.0.1:1349/hud/ at 1920 × 1080.
  4. Go live. Spectate a match or GOTV – or start the built-in demo match to try everything without CS2.

Detailed guides for camera control, Stream Deck and OBS are in the documentation.

FAQ

Is it really free? What's the catch?

No catch. TacAM HUD is open source under the GPL-3.0: no account, no subscription, no premium features, no ads, no donation button. It was built because paid broadcast HUDs are too expensive for most community events.

Is it safe to use? What about VAC?

The HUD only reads CS2's official Game State Integration, which Valve provides for exactly this. Only camera control needs CS2 started through HLAE with -insecure – on the observer PC, for demos, GOTV and your own servers. Players' PCs are never touched. See What runs where.

Does it work with GOTV and demos?

Yes – the observer spectates a GOTV broadcast, a server or plays back a demo, and TacAM receives the game state. Camera paths work in all three.

Windows only?

The desktop app with automatic updates is for Windows, where CS2 observers usually are. The server also runs on Linux with Node.js, and the HUD is a web page – any OBS can show it.

Why does Windows SmartScreen warn about the installer?

The installer is not code-signed yet. Free signing through the SignPath Foundation for open-source projects is being set up; until then choose More info → Run anyway. Every installer is built by GitHub Actions from the public source code.

Does TacAM HUD collect data?

No telemetry, no tracking. The app only checks GitHub for updates, downloads HLAE when you ask for it, and talks to the integrations you configure (OBS, Companion …). Details in the privacy section.

Can I use my own design or my existing HUD?

Yes. The theme editor changes colors, fonts, sponsors and logo; LHM and JTs-Hud HUDs can be imported and keep working with camera control, OBS and Stream Deck. Or fork the project – that's what open source is for.

May I use it for a tournament with prize money or sponsors?

Yes, for any event. The GPL-3.0 only asks one thing: if you distribute a modified version, publish its source code too. A mention of TacAM HUD in your stream is appreciated, not required.
